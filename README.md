# Traffic-Rule-Simulator-Game-Unity
Gamified Unity driving simulator for learner license training. Bridges theory-practice gap with levels, badges, real-time rule feedback, and hazard scenarios on standard PCs.

## Unity Version
This project is built with **Unity 2022.3**.

## Setup After Cloning
1. Clone this repository to your local machine.
2. Open **Unity Hub**.
3. Make sure **Unity 2022.3** is installed in Unity Hub before opening the project.
4. In Unity Hub, click **Open** and select the cloned project folder.
5. Let Unity import the project files and packages completely on first launch.
6. If Unity prompts you to upgrade packages or project settings, review the prompt and continue only if it targets **Unity 2022.3** compatibility.
7. Open the required scene from the `Assets/Scenes` folder and press **Play** to run the project.

## Notes
- First import may take a few minutes depending on your machine.
- It is recommended to open the project using the same Unity major/minor version to avoid compatibility issues.
